# Les types de maintenances : 
## Corrective :
Vise à corriger les erreurs possibles (Correction des erreurs d'input humaine)

## Evolutive : 
Vise à conservé l'évolutivité du code (Refactorisation des fonctions)

## Préventive : 
Permet de prévenir les erreurs possibles (test unitaires)

# Procesus de traitement d'un incident
Il faut :
1. Analyser l'incident, donc en déterminer sa cause
2. Trouver une solution viable pour résoudre le problème
3. Mettre en place de test afin de vérifier le bon fonctionnement de la solution apportée

# Gestion des demandes d'évolutions
Il faut : 
1. Analyser la demande, c'est à dire voir si elle est nécessaire, ce qu'elle apporte, et ce qu'elle coute
2. Vérifier la possibilité d'implémentation (ce qui veut dire possiblement refactoriser le code actuel)
3. Faire valider la demande 
4. Implémenter la demande 
5. Mettre en place des test afin de vérifier que tout fonctionne comme prévu
